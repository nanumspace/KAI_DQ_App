### 바뀐 점

- **기본 명세가 v3 로 바뀝니다.** 의뢰사 2026-09-30 매뉴얼에 10/1 검토 결정(제안 21건 중 14건 채택)을 반영한 판입니다. 코호트마다 질환 본표 하나와 핵심 표를 그대로 채워 넣는 구조이며, 표 17개 · 필드 169개 · 규칙 389개(구조 367 + 교차 22)입니다. 코호트당 247~287개 규칙이 적용됩니다.
- 9/30 매뉴얼과 달라진 점
  - 항암요법 표는 `SACT`(키 `sact_id`)이고, `sact_id` 는 항종양제(ATC L01) 투여일 때만 필수입니다.
  - `DRUG_EXPOSURE.note_id` 는 없어지고 SMILES 는 성분별 참조표 `DRUG_INGREDIENT_STRUCTURE` 로 옮겼습니다.
  - 폐암에 ICD-O-3 조직형·원발 부위 코드와 AJCC 판수, 림프종에 ICD-O-3 조직형 코드가 추가되었습니다.
  - `OBSERVATION.value_as_concept_id` 와 원천 코드(`*_source_value`) 열이 추가되었습니다.
  - `cell_of_origin` 은 DLBCL 일 때만 필수이고, 소세포폐암은 제한기/확장기(LD/ED) 병기를 쓸 수 있습니다.
- v2(OMOP CDM 5.4 + K-AI 확장)와 v1 은 **설정 → 명세 판**에서 계속 고를 수 있습니다. '서식 변환' 메뉴는 v2 를 골랐을 때만 보입니다.
