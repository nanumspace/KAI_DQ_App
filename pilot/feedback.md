## 규칙 이의

오탐이라고 보거나, 규칙이 병원 관행과 맞지 않거나, 뜻을 모르겠는 규칙을 적습니다. 많으면 `feedback_rules.csv` 에 표로 적어도 됩니다.

| 규칙 ID | 판정 | 설명 (왜 그렇게 보는지, 병원에서는 어떻게 기록하는지) |
|---|---|---|
| 예: SEM3-COM-005 | 오탐 | 외래 처방의 days_supply 를 1회 수령량으로 적어 약물 종료일 계산이 어긋난다 |
| | | |

판정은 셋 중 하나입니다.

- **오탐** — 데이터는 맞는데 규칙이 잘못 울린다.
- **정탐이지만 못 고침** — 규칙이 맞고 데이터 문제도 맞는데, 원천 시스템에서 고칠 수 없다(예: 과거 기록의 결측).
- **모르겠음** — 규칙의 뜻이나 조치 방법을 모르겠다.
