# 3. 검증 실행

순서는 **서식 변환 → 검증 실행** 입니다. 서식을 쓰지 않는 시험(견본 데이터 등)이면 서식 변환은 건너뜁니다.

## 서식 변환

담당자가 채운 서식 CSV 들을 저장 테이블로 바꿉니다. 왼쪽 메뉴의 **서식 변환** 화면입니다.

1. **코호트**를 고릅니다.
2. **폴더 → 선택**으로 서식 CSV 가 든 폴더를 고릅니다. 파일 하나가 서식 하나이고 파일 이름이 서식 이름(예: `PATHOLOGY_REPORT.csv`)입니다.
3. **레코드로 바꾸기**를 누릅니다.

결과 화면은 네 부분입니다.

| 부분 | 뜻 |
|---|---|
| 변환 결과 | 읽은 서식 수와 행 수, 만들어진 저장 테이블별 레코드 수, **저장 위치**. 이 폴더를 검증 실행에 넣습니다 |
| 서식으로는 만들 수 없는 표 | 환자·방문·약물·사망·검체·기록 등 EHR 에서 그대로 뽑아야 하는 표. **EHR 추출본 폴더로 따로** 넣어야 합니다 |
| 폴더에 없던 서식 | 이 코호트가 채워야 하는데 파일이 없던 서식. 해당 사례가 없으면 비워 둬도 됩니다 |
| 확인할 점 | 값 집합에 없는 코드, `person_id` 가 없는 행 등. 서식을 고치고 다시 변환합니다 |

변환이 만드는 행의 ID 는 9,000,000,000 부터 매겨져 EHR 추출본의 ID 와 부딪히지 않습니다. 결과 폴더는 앱 데이터 폴더 아래 `crf-staging/<코호트>/` 에 놓입니다.

## 검증 실행

**검증 실행** 화면은 위에서 아래로 네 단계입니다.

### ① 코호트와 파일

1. **코호트**를 고릅니다 (폐암, 유방암, 대장암, 대사이상지방간, 당뇨병, 림프종). 필요한 표 17~19개가 아래에 나열됩니다.
2. 파일을 넣습니다. 세 가지 방법이 있습니다.
   - 파일이나 폴더를 창 안의 점선 영역에 **끌어다 놓기**
   - **파일 선택**으로 CSV 여러 개 또는 엑셀 한 파일 고르기
   - **폴더 선택**으로 폴더를 **여러 개** 고르기 — EHR 추출본 폴더와 서식 변환 결과 폴더를 한 번에

폴더를 여럿 넣으면 파일 목록 위에 폴더 칩(`EHR추출본 · 14개 ×`)이 서고, × 로 그 폴더에서 온 파일을 한꺼번에 뺄 수 있습니다. 파일마다 어느 폴더에서 왔는지 이름 아래에 적힙니다.

### ② 테이블 대응과 사전 점검

파일을 넣으면 대응표가 나타납니다. 왼쪽이 코호트에 필요한 표, 오른쪽이 프로그램이 골라 놓은 파일(또는 시트)입니다.

- 자동 대응이 틀렸으면 오른쪽 드롭다운에서 다른 파일을 고릅니다.
- 같은 이름의 파일이 두 폴더에서 오면 `MEASUREMENT.csv (EHR추출본) + MEASUREMENT.csv (서식변환결과) (합침)` 으로 표시되고 합쳐 읽습니다. 하나만 쓰려면 드롭다운에서 그 파일을 고릅니다.
- **미리보기**로 앞부분 몇 줄을 확인할 수 있습니다.

사전 점검 결과가 함께 표시됩니다.

| 표시 | 뜻 | 실행 |
|---|---|---|
| 오류 | PERSON 이 없음, 기본키나 person_id 컬럼이 없음, 파일을 읽을 수 없음(빈 파일·알 수 없는 인코딩), 중복된 컬럼명 | 차단됨. 먼저 해결해야 합니다 |
| 주의 | 표가 없음(빈 파일이라도 넣기를 권함), 명세와 다른 컬럼, 날짜 형식이 다른 표본, 합치는 파일들의 컬럼 구성이 다름 | 가능하지만 결과에 위반으로 나타날 수 있습니다 |
| 참고 | 대소문자·별칭 컬럼명, `NULL` 글자, `.0`, `00:00:00`, 구분자, 파일 합침 | 알아서 처리됩니다. 무엇을 했는지 보고서에 적힙니다 |

### ③ 실행

**실행 이름**을 적고(예: `2026-09 제출본`. 비우면 폴더 이름), **검증 실행일**을 확인한 뒤 **검증 실행**을 누릅니다. 이 날짜 이후의 날짜는 "미래 날짜"로 판정됩니다. 기본값은 오늘이며 **설정**에서 바꿀 수 있습니다. 데이터를 뽑은 날로 맞추는 것이 좋습니다.

진행률이 표시되며 화면은 그동안 계속 쓸 수 있습니다. 환자 100명 규모는 수 초, 2,000명(행 50만) 규모도 10초 안팎입니다.

넣은 파일은 실행 폴더의 `input/` 안에 `<TABLE>.csv`(UTF-8, 쉼표 구분, 명세 컬럼명)로 정규화되어 보관됩니다. 원본 파일은 바뀌지 않습니다.

### ④ 결과와 출력물

실행이 끝나면 요약이 나옵니다.

| 항목 | 뜻 |
|---|---|
| 검사 행 수 | 규칙이 검사한 행의 총수 |
| 위반 건수 | 규칙에 걸린 행의 총수 |
| 오류율 | 위반 건수 ÷ 검사 행 수 |
| 규칙 통과·실패·건너뜀 | 규칙 단위 결과. 표가 없어 볼 수 없었던 규칙은 건너뜁니다 |

아래에 출력물 5종이 나열되며, 각 파일을 바로 열거나 **실행 폴더 열기**로 폴더를 볼 수 있습니다. **결과 폴더로 내보내기 (전체)**를 누르면 다섯 파일과 안내 README를 원하는 폴더 하나에 담아 줍니다. 파일별 내용과 제출 규칙은 [4. 출력물 읽기와 제출](04-output.md)에 있습니다.

## 다시 실행하기

데이터를 고친 뒤 같은 코호트로 다시 실행하면 새 실행으로 기록됩니다. 이전 실행과의 위반 건수 변화는 **통계 모니터링** 화면에서 추이로 볼 수 있습니다. 필요 없는 실행 기록은 같은 화면에서 지울 수 있습니다.
