# Quality Validator 사용자 설명서

병원 담당자가 코호트 데이터를 제출하기 전에 스스로 품질을 점검하는 프로그램입니다. 코호트 테이블 파일(질환 본표와 환자·방문·약물·검사 등 공통 표)을 넣고 실행하면 기본 명세 **v3** 의 검증 규칙 389개(코호트마다 247~287개가 적용)를 검사해 보고서를 만듭니다.

- 병원 데이터베이스에 접속하지 않습니다. 내보낸 파일만 읽습니다.
- 네트워크 통신을 하지 않습니다. 결과는 사용자 컴퓨터에만 저장됩니다.
- 환자 단위 정보는 프로그램 밖으로 나가지 않습니다. 중앙에 보내는 파일은 집계만 담은 `submission.json` 하나입니다.

## 데이터가 오가는 길

```
코호트 테이블 (PERSON · VISIT_OCCURRENCE · … · 질환 본표 · SACT …)  ──→  검증 실행  →  보고서 · submission.json
  병원이 v3 양식에 맞춰 직접 채움 (CSV · 엑셀 · 폴더)
```

기본 명세 v3 에서 병원은 **표를 직접 채웁니다.** 코호트마다 질환 본표 하나와 OMOP 형식 공통 표(PERSON, VISIT_OCCURRENCE, PROCEDURE_OCCURRENCE, DRUG_EXPOSURE, CONDITION_OCCURRENCE, MEASUREMENT, OBSERVATION, NOTE), ADVERSE_EVENT, 항암요법 SACT, DRUG_INGREDIENT_STRUCTURE 를 만들어 **검증 실행** 화면에 넣습니다. 서식을 따로 채워 변환하는 단계는 없습니다. (이전 판 v2 에서만 **서식 변환** 단계가 있습니다.)

## 화면 구성

왼쪽 메뉴에 7개 화면이 있습니다(v2 를 고르면 **서식 변환**이 더해져 8개). 처음 열면 **검증 실행** 화면이 나옵니다.

| 메뉴 | 용도 |
|---|---|
| 검증 실행 | 코호트와 파일을 넣고 검증을 실행합니다. 결과 파일을 내보냅니다 |
| 결과 보고서 | 실행 요약, 실패 규칙, 분류별 집계, 보고서 원문 |
| 오류 현황 조회 | 위반 행을 규칙·테이블·심각도로 걸러 보고 CSV로 내보냅니다 |
| 대시보드 | 오류 유형별 통계, 질환별 최신 결과, 적용 규칙, 후속 조치 가이드, 실행 추이 |
| 통계 모니터링 | 실행 이력 목록과 위반 건수·오류율 추이, 실행 기록 삭제 |
| 검증 규칙 관리 | 규칙 조회·검색, 규칙 설명과 조치 안내 |
| 설정 | 명세 판, 명세·규칙 위치, 검증 실행일 기본값, 데이터 저장 위치 |

## 명세 판

이 설명서는 기본 판 **v3** 기준입니다. v3 는 2026-09-30 의뢰사 매뉴얼에 2026-10-01 검토 결정(제안 21건 중 14건 채택)을 반영한 명세로, 표 17개 · 필드 169개 · 규칙 389개(구조 367 + 교차 22)입니다. 코호트마다 질환 본표 하나와 공통 표를 쓰며 병원이 표를 직접 채웁니다.

| 판 | 규칙 | 입력 | 언제 쓰나 |
|---|---|---|---|
| **v3 (기본)** | 389개 | 표를 직접 채움 | 새로 제출하는 모든 경우 |
| v2 | 1,078개 | 서식을 채우고 **서식 변환** (OMOP CDM 5.4 + K-AI 확장) | 이전에 v2 로 낸 제출본을 다시 열 때 |
| v1 | 1,196개 | 질환별 단일 표 | 이전에 v1 로 낸 제출본을 다시 열 때 |

이전 판은 **설정 → 명세 판**에서 고를 수 있고, 판을 바꾸면 코호트·규칙·양식·견본 데이터가 함께 바뀝니다. **서식 변환** 메뉴는 v2 를 골랐을 때만 보입니다. v2 사용법은 이 설명서의 "v2 로 제출한다면" 안내([2장](02-input.md), [3장](03-run.md))를 보세요.
