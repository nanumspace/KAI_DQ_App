# Quality Validator 사용자 설명서

병원 담당자가 코호트 데이터를 제출하기 전에 스스로 품질을 점검하는 프로그램입니다. 코호트 테이블 파일을 넣고 실행하면 검증 규칙 1,196개를 검사해 보고서를 만듭니다.

- 병원 데이터베이스에 접속하지 않습니다. 내보낸 파일만 읽습니다.
- 네트워크 통신을 하지 않습니다. 결과는 사용자 컴퓨터에만 저장됩니다.
- 환자 단위 정보는 프로그램 밖으로 나가지 않습니다. 중앙에 보내는 파일은 집계만 담은 `submission.json` 하나입니다.

## 순서

| 단계 | 문서 | 내용 |
|---|---|---|
| 1 | [설치](01-install.md) | Windows와 macOS 설치, 보안 경고 안내 |
| 2 | [입력 파일 준비](02-input.md) | 코호트 테이블을 CSV 또는 엑셀로 준비하는 방법, 입력 양식 내려받기 |
| 3 | [검증 실행](03-run.md) | 코호트 선택, 파일 넣기, 테이블 대응 확인, 실행 |
| 4 | [출력물 읽기와 제출](04-output.md) | 결과 파일 5종, 심각도와 조치 안내, 중앙 제출 규칙 |
| 5 | [자주 묻는 질문](05-faq.md) | 파일이 인식되지 않을 때, 한글이 깨질 때, 실행이 막힐 때 |

## 화면 구성

왼쪽 메뉴에 7개 화면이 있습니다. 처음 열면 **검증 실행** 화면이 나옵니다.

| 메뉴 | 용도 |
|---|---|
| 검증 실행 | 코호트와 파일을 넣고 검증을 실행합니다. 결과 파일을 내보냅니다 |
| 결과 보고서 | 실행 요약, 실패 규칙, 분류별 집계, 보고서 원문 |
| 오류 현황 조회 | 위반 행을 규칙·테이블·심각도로 걸러 보고 CSV로 내보냅니다 |
| 대시보드 | 오류 유형별 통계, 질환별 최신 결과, 적용 규칙, 후속 조치 가이드, 실행 추이 |
| 통계 모니터링 | 실행 이력 목록과 위반 건수·오류율 추이, 실행 기록 삭제 |
| 검증 규칙 관리 | 규칙 1,196개 조회·검색, 규칙 설명과 조치 안내 |
| 설정 | 명세·규칙 위치, 검증 실행일 기본값, 데이터 저장 위치 |
