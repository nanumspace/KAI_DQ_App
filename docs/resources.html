자료실

앱의 기본 명세에서 그대로 만든 자료입니다. 병원은 앱을 설치하기 전에 입력 양식을 받고, 어떤 규칙으로 검사받는지 미리 볼 수 있습니다. 명세나 규칙이 바뀌면 이 페이지도 다음 배포 때 함께 바뀝니다.

내려받기

엑셀 양식은 시트 하나가 테이블 하나이고 '명세' 시트에 컬럼 설명이 있습니다. CSV 묶음은 테이블마다 헤더만 있는 파일입니다. 앱의 '입력 양식 내려받기'와 같은 모양입니다.

코호트표적용 규칙입력 양식견본 데이터 기대 결과 (clean / dirty 위반 수)

견본 데이터(100명 가상 코호트, clean·dirty)는 최신 릴리스에서 받습니다. 폴더째 앱의 검증 실행 화면에 넣으면 위 기대 결과와 같은 수가 나와야 합니다.

검증 규칙

구조 규칙은 명세에서 자동 생성되고, 교차 규칙은 여러 표를 함께 보는 SQL 입니다. 분류는 Kahn 프레임워크(적합성 Conformance · 완전성 Completeness · 타당성 Plausibility)를 따릅니다. 심각도 error 는 적재 거부 수준, warning 은 검토 필요입니다.
